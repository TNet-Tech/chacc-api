# Security Policy

## Supported versions

Security fixes are applied to the latest release published on
[PyPI](https://pypi.org/project/chacc-api/).

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private reporting instead:
**Security tab → "Report a vulnerability"** on this repository.

Include what you found, how to reproduce it, and the version you tested. You can
expect an acknowledgement within a few days; we will keep you updated until a fix
is released and credit you in the changelog if you wish.
